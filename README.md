# FitLog — Gym Companion App

FitLog is a dark, no-nonsense gym companion web application built for fitness enthusiasts to pick lifts, build daily routines, and track their workout progress seamlessly.

## Technologies Used
- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Icons:** Lucide React
- **Data Persistence:** Browser LocalStorage

## 5 Key Features
1. **Workout Library:** Browse through a comprehensive collection of workouts categorized by muscle groups, equipment, and difficulty.
2. **Dynamic Sorting & Filtering:** Sort workouts easily by duration, calories burned, or rating.
3. **Daily Plan Management:** Add workouts to today's plan, monitor total workout duration, and view cumulative calories burned.
4. **Interactive Controls:** Mark planned workouts as "Done" or remove them instantly with real-time toast notifications.
5. **Responsive Dark UI:** Designed with a modern, high-contrast dark theme optimized for both desktop and mobile users.
